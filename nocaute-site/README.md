# noCauTe — links da equipe

1. Abra `index.html` no navegador para visualizar.
2. Edite a lista `integrantes` no início de `script.js`. Use URLs completas com https://. Para fotos, crie uma pasta `assets` e informe, por exemplo, `assets/ana.jpg`.
3. Se quiser, configure os links do projeto na variável `projeto`.
4. Publique os arquivos na raiz de um repositório público no GitHub.
5. Em Settings > Pages, selecione Deploy from a branch, main e /(root). Salve.
6. Use o endereço publicado para gerar o QR Code. Teste todos os links no celular antes de imprimir.

Os quatro integrantes são ilustrativos, os links vazios ficam desativados e a identidade visual usa preto e vermelho como proposta inicial. Não há dependências externas, coleta de dados ou banco de dados.
